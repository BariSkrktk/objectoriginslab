Privacy Policy

Object Origins Lab uploader · Last updated: September 22, 2026

What this application is

The Object Origins Lab uploader is a private tool operated by the owner of the Object Origins Lab YouTube channel. It is used only by the channel owner, on the owner's own computers, to manage the owner's own channel. It is not offered to or used by anyone else.

What data it accesses

With the channel owner's explicit authorization through Google OAuth, the application uses the YouTube Data API to:

  • upload videos to the owner's channel and set their title, description, tags and privacy settings;
  • read the owner's channel information, video statistics and the comments posted on the owner's own videos.

The application does not access any other Google account and does not collect personal data from viewers or any other person.

How data is stored

Authorization tokens are stored only on the channel owner's own computers. They are not uploaded to any server, shared with third parties, sold, or used for advertising. No analytics or tracking of any kind is included in the application.

Google and YouTube policies

This application uses YouTube API Services. By using YouTube through this application you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page: myaccount.google.com/permissions. Revoking access makes the stored tokens unusable.

Contact

Questions about this policy can be sent through the Object Origins Lab YouTube channel.
