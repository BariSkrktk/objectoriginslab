Object Origins Lab

Short visual documentaries about the surprising history behind everyday objects.

Object Origins Lab is a YouTube channel that tells the strange history, accidental inventions and clever designs behind the things people use every day.

Watch the channel: Object Origins Lab on YouTube

About this application

The "Object Origins Lab uploader" is a private tool used only by the channel owner to upload videos to the Object Origins Lab YouTube channel and to read the channel's own statistics. It is not offered to the public and does not access any other user's data.
